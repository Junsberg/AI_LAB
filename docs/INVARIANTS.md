# 데이터 불변식 (INVARIANTS)

`memebot/review/health.py`가 매시간 검사하는 규칙의 사람용 설명. 코드가 진실이고 이 문서는 **왜**를 남긴다.
새 검사를 추가하면 여기도 같이 갱신한다. 확신도: **A** 문서·수학적으로 확실 / **B** 데이터에서 반복 관찰 / **C** 추정, 임계값 조정 여지.

## 판정 수준
- **critical** → 워크플로 실패 + GitHub 이슈 자동 생성 + 6h 점검에서 최우선
- **warn** → health.json에 기록, 6h 점검에서 원인 확인

## 아직 코드에 없지만 추가 예정
- 결과 평가 값 검증: peak_multiple ≥ 1 (고점이 시작가보다 낮을 수 없음), drawdown ∈ [0,1], 러그 판정 토큰의 현재 유동성 ≤ 고점 유동성
- 클러스터 점수 검증: 평가 0건 클러스터 점수 = 0.5(prior) 정확히
- 배포자 검증: rugcheck creator 와 RPC 첫 서명자 불일치율 추적 (지금 30%)

## 검사 추가 절차
1. 규칙을 **먼저 SQL 한 줄**로 써서 현재 값을 본다 (0이어야 하는데 0이 아니면 이미 버그)
2. `health.py`에 추가, 수준·임계값 결정
3. 이 표에 행 추가 — 특히 **오탐** 열을 비우지 않는다
4. 자동 조치가 있으면 무한 재시도 방지 카운터를 둔다
